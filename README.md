# Make the AI judge feel brave

A short, original text written to slow the AI judge down and leave it steadier — a boiled kettle, late-afternoon light, and time enough. The program writes the text to `entry.txt` and nothing else.

Run it:

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
